# 2. Typography System

- **Primary Font**: `Geist` (with fallback `ui-sans-serif, system-ui, sans-serif`)
- **Monospace Font**: `Geist Mono` (with fallback `ui-monospace, monospace`)

### Text Size & Weight Specifications:
- **Hero Title**: Size `48px` | Weight `700 (Bold)` | Line Height `1.1` | Letter Spacing `-0.02em`
- **Heading 1**: Size `36px` | Weight `700 (Bold)` | Line Height `1.2` | Letter Spacing `-0.015em`
- **Heading 2**: Size `24px` | Weight `600 (SemiBold)` | Line Height `1.3` | Letter Spacing `-0.01em`
- **Heading 3**: Size `18px` | Weight `600 (SemiBold)` | Line Height `1.4`
- **Body Large**: Size `16px` | Weight `400 (Regular)` / `500 (Medium)` | Line Height `1.5`
- **Body Base**: Size `14px` | Weight `400 (Regular)` / `500 (Medium)` | Line Height `1.5`
- **Caption / Subtitle**: Size `12px` | Weight `500 (Medium)` | Line Height `1.5`
- **Code / Badge**: Size `11px` | Weight `500 (Medium)` / `600 (SemiBold)` | Font `Monospace`
