#  3. Border Radius Tokens

| Token Name | Radius | Design Usage |
| :--- | :--- | :--- |
| **`--radius-sm`** | `4px` (`0.375rem`) | Badges, small tags, and code blocks |
| **`--radius-md`** | `8px` (`0.5rem`) | Small buttons, form inputs, and menu items |
| **`--radius-lg`** | `10px` (`0.625rem`) | Base component foundation and buttons |
| **`--radius-xl`** | `14px` (`0.875rem`) | Small cards and popovers |
| **`--radius-2xl`** | `18px` (`1.125rem`) | Main gallery cards and modals |
| **`--radius-full`** | `9999px` | Pill buttons, avatars, and badges |
