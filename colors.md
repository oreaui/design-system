# Color Palette

A complete reference for Orea's color system, including semantic color tokens, transparency values, and brand colors.

---

## Neutral & Surface Colors

| Token | HEX | RGB | Usage |
| :--- | :--- | :--- | :--- |
| **Canvas** | `#080808` | `rgb(8, 8, 8)` | Primary application background |
| **Surface** | `#0A0A0A` | `rgb(10, 10, 10)` | Default surface for cards, panels, and containers |
| **Surface Elevated** | `#161616` | `rgb(22, 22, 22)` | Elevated surfaces such as dialogs, popovers, and floating panels |
| **Border Strong** | `#262626` | `rgba(38, 38, 38, 0.80)` | High-emphasis borders and separators |
| **Border Subtle** | `#262626` | `rgba(38, 38, 38, 0.60)` | Low-emphasis borders, outlines, and hover states |
| **Text Muted** | `#737373` | `rgb(115, 115, 115)` | Disabled text, helper text, placeholders, captions |
| **Text Secondary** | `#A1A1A1` | `rgb(161, 161, 161)` | Secondary content and supporting text |
| **Text Primary** | `#D4D4D4` | `rgb(212, 212, 212)` | Default body text |
| **Text Strong** | `#E5E5E5` | `rgb(229, 229, 229)` | High-emphasis content and labels |
| **Heading** | `#FAFAFA` | `rgb(250, 250, 250)` | Headings and primary titles |
| **White** | `#FFFFFF` | `rgb(255, 255, 255)` | Maximum contrast elements, icons, and emphasis |

---

## Alpha Transparencies

| Token | Value | Usage |
| :--- | :--- | :--- |
| **White / 25%** | `rgba(255, 255, 255, 0.25)` | High-emphasis overlays, borders, and highlights |
| **White / 15%** | `rgba(255, 255, 255, 0.15)` | Glass surfaces, dividers, and subtle overlays |
| **White / 12%** | `rgba(255, 255, 255, 0.12)` | Disabled and inactive borders |
| **White / 6%** | `rgba(255, 255, 255, 0.06)` | Low-emphasis surface overlays |
| **White / 3%** | `rgba(255, 255, 255, 0.03)` | Hover and pressed state backgrounds |
| **Black / 30%** | `rgba(0, 0, 0, 0.30)` | Drop shadows and depth effects |

| **Success** | `#10B981` | `rgb(16, 185, 129)` | Success states and positive feedback |
