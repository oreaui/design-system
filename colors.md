#  1. Color Palette & HEX Tokens

### Neutral & Surface Colors

| Token / Element Name | HEX Code | RGB / Opacity Values | Design Layer / Usage |
| :--- | :--- | :--- | :--- |
| **Canvas / Main Background** | `#080808` | `rgb(8, 8, 8)` | Main canvas & page background (`get-start`) |
| **Card Background** | `#0A0A0A` | `rgb(10, 10, 10)` | card background |
| **Surface Card Background** | `#161616` | `rgb(22, 22, 22)` | Secondary card and dialog background |
| **Overlay / Border Dark** | `#262626` | `rgba(38, 38, 38, 0.8)` | Layered borders and button backgrounds |
| **Overlay Subtle** | `#262626` | `rgba(38, 38, 38, 0.6)` | Hover background for containers and inputs |
| **Muted Text / Description** | `#737373` | `rgb(115, 115, 115)` | Subtitle descriptions, secondary text, and labels |
| **Subtitle Text** | `#A1A1A1` | `rgb(161, 161, 161)` | Subtitles and card descriptions |
| **Light Gray Body** | `#D4D4D4` | `rgb(212, 212, 212)` | Main body text and cards |
| **Foreground Text** | `#E5E5E5` | `rgb(229, 229, 229)` | Bright white text and code values |
| **High-Contrast Heading** | `#FAFAFA` | `rgb(250, 250, 250)` | Headings and main titles |
| **Bright Heading** | `#F5F5F5` | `rgb(245, 245, 245)` | Component and card titles |
| **Pure White** | `#FFFFFF` | `rgb(255, 255, 255)` | Icons, prominent buttons, and bold text |
